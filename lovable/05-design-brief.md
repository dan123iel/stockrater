---

## What exists (current design — can be changed)

**Color palette:** Monochrome grayscale
- white #FFFFFF (backgrounds)
- gray scale: #D6D6D6 → #000000
- Functional colors: green #16a34a (BUY/up), red #dc2626 (SELL/down), amber #d97706 (HOLD/warn)

**Fonts:** Interdisplay (headlines) + Chivo Mono (labels/mono)

**Style:** Editorial, minimal, no color accents on backgrounds, large typography

---

## What must stay (non-negotiable UX)

- BUY = green, HOLD = amber, SELL = red — these are universal finance conventions
- Score card with gauge animation
- Factor breakdown with source attribution visible
- "Research tool only · Not financial advice" disclaimer always visible
- Section labels in monospace: [ LABEL ]
