# pondex_ Landing Page — Research-Backed Improvement Plan
_Date: 2026-07-26 · Sources: CXL, NNGroup, Unbounce, ContentSquare, Kahneman/Tversky_

## Key Research Findings

1. **Fintech = exception to simplicity rule** — Domain authority language converts better than 5th grade copy in financial services (Unbounce, 57M conversions)
2. **Specific numbers in hero > any visual** — Concrete outcome numbers (Acorns, Chime, SoFi) outperform all illustration styles
3. **Animated counters: 14–28% CTA lift** — Drawing eye to credibility stats at trust-evaluation moment (Acorns, M1 Finance standard pattern)
4. **Hero redesign alone = 15% lift; behavioral data = 38%** — Above-the-fold changes have disproportionate impact
5. **Loss aversion 2x stronger than gain** — Lead with "inaction risk", not return promises (Betterment, Wealthfront pattern)
6. **Product UI screenshots > illustrations > stock photos** — Real UI answers "does this work?" (NNGroup)
7. **Fintech: stillness first, motion below fold** — Hero animations trigger skepticism in financial context (Robinhood, Wealthfront)
8. **Trust marks in hero, not footer** — Authority principle: data sources above fold = conversion element, not footnote
